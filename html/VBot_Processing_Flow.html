3. Nguồn đầu vào

Mic local

Wake word → xin owner mic → thu frame qua cổng đọc chung → STT → transcript.

Streaming client

WebSocket tạo session và generation → queue PCM có giới hạn → STT backend → mode xử lý → phản hồi client.

HTTP API

Text/control/status/update. Không đọc mic nếu request đã có text. Update được bàn giao Update Manager.

MQTT

Lệnh theo registry/topic, điều khiển state và phản hồi sau khi thay đổi runtime hoàn tất.

Scheduler

Nhắc việc/lịch chạy nền nhưng vẫn phải tuân thủ audio ownership và media takeover.

XiaoZhi / Home Assistant

Yêu cầu giao thức hoặc điều khiển entity được validate trước khi gọi handler.

5. Xử lý ý định

  1. Chuẩn hóa input và nhận processing owner.
  2. Tách multi-command nếu có.
  3. Thử lệnh hệ thống, mic, âm lượng và media ưu tiên.
  4. Thử Home Assistant, lịch, thời tiết, nhắc việc, radio, podcast, báo và nhạc.
  5. Gọi Custom Skill nếu được bật.
  6. Chuyển Assistant khi không handler nào nhận.
  7. Phát kết quả và nhả đúng owner.

Custom Skill trả True

Đã xử lý xong; dừng router phía sau.

Trả False/None

Bỏ qua; VBot tiếp tục handler mặc định.

Exception

Ghi log có context; cleanup và thử fallback nếu hợp lệ.

Là bản bảo vệ chính trước cập nhật.

Chỉ cảnh báo; giữ backup local và tiếp tục cập nhật.

Rollback code và Config, phục hồi service và ghi result.

Chạy thủ công file Python không tải Google Drive. Quyền Drive là private hoặc anyone_with_link; refresh token luôn được merge với token mới trước khi lưu.

16. Checklist phát triển

  1. Xác định coroutine/thread, owner và generation.
  2. Validate input và schema dữ liệu ngoài.
  3. Đặt timeout; chuyển I/O blocking ra worker.
  4. Không log secret/token/password.
  5. Dùng state/facade chung cho media.
  6. Cleanup trong mọi nhánh success/error/cancel.
  7. Không dùng kết quả worker cũ.
  8. Ghi file nguyên tử; không phát file tạm.
  9. Giữ hợp đồng các hàm Dev.
  10. Thêm test success, timeout, cancel và reconnect.
