Hướng dẫn sử dụng nhanh (1 file độc lập):
1. Dùng trực tiếp trong LAN: Mở http://<IP-VBot>/VBot_Face_Client.html từ điện thoại/tablet/PC.
2. Chạy độc lập trên thiết bị khác: Tải hoặc sao chép riêng file VBot_Face_Client.html sang máy khác, mở bằng trình duyệt → nhập ws://<IP-VBot>:5003 → bấm Kết nối (tự lưu cho lần sau).
3. Thao tác nhanh: Chạm trực tiếp vào khuôn mặt để Nói ngay (Skip_WakeUP) hoặc dừng loa khi đang đọc.
4. Nếu trình duyệt chặn Micro trên HTTP LAN: Mở Chrome → chrome://flags/#unsafely-treat-insecure-origin-as-secure → Bật và thêm địa chỉ trang hiện tại rồi khởi động lại Chrome (hoặc chạy python3 -m http.server 8080 rồi mở http://localhost:8080/VBot_Face_Client.html).
